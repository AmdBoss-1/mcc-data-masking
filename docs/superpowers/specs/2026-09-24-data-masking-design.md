## 1. 背景与目标

主闭环（用户核心诉求）：

1. `mask` 源数据 → 脱敏副本 + 加密码本（码本留本机，绝不出门）
2. 脱敏副本发给 AI / 远程支持
3. AI 产物（报告、md、xlsx、csv、对方回传件）里带着**假值**
4. `unmask <AI产物>` → 按码本把假值换回真值，得到"含 AI 生成内容的真值版本"

**关键语义**：`unmask` 的输入是**任何含假值的文件**，不限于原文件副本。

次要目标：同一引擎日后供 B 线（脱敏演示库）、C 线（套件内脱敏导出）复用；本设计只覆盖 v1 = 引擎 + A 线（文件脱敏/还原/查回）。

## 2. 范围

### v1 _in
- 命令：`mask` / `unmask` / `lookup` / `purge`
- 格式（mask 与 unmask 双向同套读写器）：
  - OOXML：`.xlsx` `.docx` `.pptx`（POI；Word/PPT 做 **run 级保格式替换**）
  - OLE 老二进制：`.xls`（HSSF，成熟）`.doc`（HWPF）`.ppt`（HSLF）——**写回自验**兜底（见 §6）
  - 文本类：`.csv` `.txt` `.log` `.md`（正则就地替换）
  - 库：H2 `.mv.db` 直开副本、`.mccbak` 解包后开副本（JDBC：敏感列 SELECT distinct → 建映射 → UPDATE；还原=反向 UPDATE）
  - SQL dump 文本（按文本规则处理：结构化正则命中即换；无表头故不做列名命中）
- PDF：**仅检测+红字报告**（第几页命中哪类敏感串），不替换
- 码本制可还原：对照查回 + 整文件/任意文件还原
- 码本 AES-256-GCM 加密、口令 PBKDF2 派生、本机存放、自动 .gitignore

### v1 _out（非目标）
- PDF 逐字替换/打码（归 D 线）；截图/文档打码（D 线）
- 演示库生成（B 线）、套件内脱敏导出（C 线）
- FPE/密钥重算式还原（已否决，选码本制）
- 数值扰动默认关闭（`--jitter` 才开）
- 云端/联网能力：无

## 3. 架构与组件

单 maven 模块（shade 打单 jar），四个组件：

- **cli**：参数解析、交互口令、摘要打印。命令面：
  - `mask <in> -o <out> [--book <dir>] [--new] [--rules f.yaml] [--jitter]`
  - `unmask <in> -o <out> [--book <dir>]`
  - `lookup <值> [--book <dir>] [--rev]`（假→真 / 真→假）
  - `purge [--book <dir>]`（覆写后删除码本）
- **rw 读写器**（双向）：Xlsx / Docx / Pptx / Xls / Doc / Ppt / Csv / Text / H2 / SqlDump；格式识别靠扩展名+魔数双判；不支持格式**明确报错**并提示另存（`.doc/.ppt` 已在 v1，其余如 `.pdf` 走检测报告、未知格式报错）
- **rules 规则引擎**：字段规则表（§4），可 `--rules` YAML 覆盖；变换器四类：FAKE_POOL / FORMAT_PRESERVING / MASK / NUMERIC_JITTER
- **codebook 码本库**：映射存取、加密落盘、增量累积、版本头

数据流（mask）：读 → 命中规则取值 → 码本取/生成假值（同码本内同原值恒同假值）→ 写副本（临时文件+原子替换）→ 码本增量加密落盘 → 摘要（替换 N 处 / M 唯一值 / 码本路径 / 凭据告警 / .doc/.ppt 自验结果）。
数据流（unmask）：读码本（口令错=GCM 认证失败，硬报错）→ 反向替换（结构化值正则整串、名称类最长优先精确串）→ 写副本 → 还原报告（替换 N 处 / 命中 M 假值 / K 个码本假值未出现）。

## 4. 字段规则表（默认，可 --rules 覆盖）

- 结构化串（任何列/任何文本都扫）：手机号→假号（号段真实感）；身份证→假证（**校验位重算**）；车牌→假牌（省+字母+5 位）；邮箱→假邮箱；税号/统一社会信用代码→假码（校验位重算）
- 列名命中（表格类）：厂名/客户/供应商/联系人/姓名/地址/电话/手机/车牌/司机 等表头词→对应变换器；词表来源=套件 entity 列名 + 常见表头
- 名称假值池：组合生成（地名+行业+字号 / 百家姓+常用名），全码本唯一、无生僻字、长度接近原值（**耐抄**：AI 逐字引用不易变形）
- 地址：省/市保留，街道门牌换假
- 数值（重量/金额/数量）：默认不动；`--jitter` 时 ±3% 内、保小数位
- 黑名单（绝不替换）：下载码、客户码、私钥、口令哈希——不替换但摘要红字告警"检测到疑似凭据"

## 5. 码本与密钥（安全口径）

- 码本单文件 `.mccmask`：头=版本+salt+KDF 参数+算法标签；体=AES-256-GCM 加密映射表（原值↔假值、按变换器分类）+元数据（创建时间、经手文件、规则版本）
- 口令：PBKDF2-HMAC-SHA256 60 万迭代；**只交互输入**，不落盘/不进环境变量/不进命令行历史；`--pass-file` 可选但默认红字警告
- 存放：默认 `./maskbook/`；初始化自动写 .gitignore 排除；不上云、不进仓库（用户铁律）
- 一码本跨文件累积；`--new` 开新码本
- 原文件永远只读；所有产出先临时后原子替换
- `purge`：覆写后删除（常态=还原完 AI 产物即毁）

## 6. 兼容性与保真策略

- OOXML 文本常被拆 run：按段落拼串定位→匹配边界切 run→只改命中段，其余格式原样
- `.doc/.ppt`（HWPF/HSLF 写回保真差）：**写回自验**——产物立即 POI 重开+全文回读，验"能打开+替换处数对得上"；验不过=该文件报错出局，绝不产坏文件；摘要单独标注自验结果
- xlsx：共享串表+字面串单元格替换；公式不动（Excel 打开自算）
- 不支持/未知格式：硬报错+另存提示，绝不静默跳过

## 7. 错误处理

口令错→GCM 认证失败硬报错；码本查不到的串→汇总"K 处未还原"不静默；写失败→不留半截文件；H2 库被占用→报错提示先停套件服务；凭据命中→红字告警不阻断。

## 8. 测试与验收

1. 往返一致：mask→unmask 与原文件比内容树逐节点相等
2. 零泄漏：脱敏产物跑敏感正则+**原值黑名单 grep**，命中即失败
3. AI 闭环仿真：脱敏→"假 AI"脚本把假值嵌进新 md/xlsx→unmask→与期望真值文档逐字比对
4. 格式保真抽查：xlsx 公式/样式/合并单元格、docx run 格式、ppt 版式前后 diff；.doc/.ppt 自验用例
5. 码本安全：错口令报错；码本明文 grep 无原值
6. 终验：全绿 + 用户拿真台账跑 mask→发 AI→unmask 一遍

测试夹具：合成数据生成 xlsx/docx/pptx/csv/txt/sql/H2；`.doc/.ppt` 夹具用本机 Office/WPS 或 LibreOffice 一次性生成（纯假数据）入库。

## 9. 决策记录

- 可还原机制=**码本制**（查回+整文件还原），否决 FPE/仅留原件
- v1 输入面=全格式（含 .xls/.doc/.ppt，用户要求"一并"），PDF 仅检测
- 技术选型=Java 单 jar（H2 只有 Java 原生读得动），否决 Python/Node
- 数值默认不扰动（AI 汇总要对得上）
- 项目独立立项于项目群（用户指定），不入套件仓库；C 线日后再复用引擎
